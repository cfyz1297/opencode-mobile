# OpenCode Mobile 0.2.20

Новая версия поверх полной базы 0.2.19 (Android versionCode 54).

- Мастер Cloudflare/ngrok: пошаговая настройка на компьютере, проверка HTTPS и пароля перед сохранением подключения. Для Cloudflare используется именованный туннель: Quick Tunnels не поддерживают необходимые SSE-события. Токен Cloudflare остаётся на компьютере.
- Интерфейс для планшетов: боковая навигация, список сессий рядом с перепиской на широком экране, поддержка изменения ориентации.
- Офлайн-история: включается отдельно в настройках или на экране истории. Недавние текстовые сообщения сохраняются в защищённом хранилище устройства и доступны для чтения без сервера. Есть удаление всех сохранённых копий; вложения, инструменты и рассуждения не сохраняются.

Сохранены исправления 0.2.19 для смены моделей, агентов и серверов, обработки ошибок авторизации и потока событий.

Проверки: 446 тестов, проверка типов и версий, пороги покрытия 80%. Для инструментируемых модулей: строки 95,72%, ветви 85,46%, функции 93,87%. Подписанный APK проверяется на Android-эмуляторе: мастер, смена сессий на планшете, офлайн-чтение после остановки сервера и перезапуска приложения, очистка истории. Подпись совпадает с ранее опубликованным приложением.

Выполнены независимые проверки кода, тестов и безопасности, а также поиск секретов. Исправлены гонки при смене сервера и сохранении/удалении локальной истории. Совместимые обновления зависимостей уменьшили аудит с 43 до 27 замечаний (0 критических, 24 высоких, 3 средних); остаточные риски, включая потенциальный путь через React Navigation/query-string, описаны в [отчёте](https://github.com/cfyz1297/opencode-mobile/blob/main/RELEASE_REVIEW_0.2.20.md). Аудит зависимостей не является чистым.

iOS JavaScript-сборка проверена; нативная сборка iOS и проверка на физическом iPad не выполнялись. Облачное подключение в один шаг исключено из этого релиза по запросу владельца.

Для установки или обновления скачайте `opencode-mobile-v2.apk`. Контрольная сумма приложена в `SHA256SUMS.txt`.
